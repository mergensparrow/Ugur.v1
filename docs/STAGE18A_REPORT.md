# Ugur Stage 18A — очистка репозитория и сборок

## Цель

Подготовить один чистый Flutter Web/PWA-проект для GitHub без изменения утверждённого интерфейса.

## Выполнено

- рабочей основой оставлен Stage 17;
- версия повышена до `1.6.1+20`;
- сохранены только актуальные workflow:
  - `.github/workflows/android.yml`;
  - `.github/workflows/deploy-web.yml`;
- APK получает однозначное имя `ugur-v1.6.1-build20-debug.apk`;
- GitHub Pages автоматически использует имя текущего репозитория в `base-href`;
- перед Android/Web-сборкой запускается проверка чистоты и целостности проекта;
- добавлен `.gitignore` для сгенерированных Flutter-папок;
- cache build tag обновлён до `stage18a`;
- валидатор запрещает старые Node/EJS-файлы и старый `build-apk.yml`.

## Что не изменялось

- все файлы `lib/**/*.dart`;
- все изображения `assets/images/*`;
- размеры, цвета, шрифты, расположение и поведение утверждённых экранов;
- текущая реализация режима дизайнера Stage 17.

Новый режим дизайнера будет отдельным этапом после подтверждения чистых Web/APK-сборок.
