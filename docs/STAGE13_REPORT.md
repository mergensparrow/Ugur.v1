# Ugur Stage 13 — mobile web viewport and owner UI controls

## Исправлено

- Мобильная веб-версия больше не переключается в крупную планшетную геометрию из-за старого 980px viewport Safari.
- GitHub Pages workflow принудительно добавляет корректный mobile viewport перед сборкой.
- Верхний голубой блок Home снова рассчитывается по компактной телефонной ветке и не оставляет лишний большой участок после кнопки.
- «Смотреть все» выровнено по центру строки заголовка.
- Добавлен экран «Размер интерфейса» в Профиле.
- Владелец может без редактирования кода менять размер всех элементов (90–108%) и отдельно размер текста (90–112%).
- Настройки сохраняются локально и имеют кнопку возврата к 100%.
