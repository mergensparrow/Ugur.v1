# Ugur Stage 17 — режим дизайнера

Добавлен локальный инструмент для самостоятельной точной подгонки размеров без изменения исходного кода и без новой сборки после каждого пиксельного исправления.

## Как открыть

На главном экране пять раз подряд нажать на логотип **Ugur**. Откроется выдвижная панель, а изменения будут сразу видны на экране.

Панель также доступна через **Профиль → Размер интерфейса**.

## Настройки

- общий масштаб элементов;
- масштаб текста;
- размер нижнего меню;
- отступ между логотипом и голубым блоком;
- вертикальный сдвиг содержимого голубого блока;
- высота карточек популярных мест;
- свободное место после кнопки «Найти гостиницы».

У каждого параметра есть ползунок и кнопки `−` / `+` для точной настройки.

## Сохранение и экспорт

- значения сохраняются локально через `SharedPreferences`;
- кнопка **Сбросить** возвращает утверждённые значения Stage 16;
- кнопка **Копировать JSON** копирует все параметры для передачи разработчику и последующей фиксации в коде.

При значениях 100% и 0 px утверждённый дизайн Stage 16 не меняется.
