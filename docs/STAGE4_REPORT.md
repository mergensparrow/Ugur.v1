# Ugur Stage 4

Исправления по тестированию на реальном Android-устройстве:

- очищен стартовый фон: удалены встроенные в изображение дубли текста и кнопки;
- стартовый экран стал адаптивнее для небольших Android-экранов;
- четыре фильтра каталога помещаются в одну строку;
- исправлен RenderFlex overflow в компактных карточках гостиниц;
- карточки каталога адаптированы под узкие экраны;
- все четыре вкладки гостиницы помещаются на экране;
- кнопки «Цены на номера», «Проверить наличие» и «Онлайн-бронирование» перенесены в подтверждённое место — после информационного содержимого;
- удалён дублирующийся текст «Показать больше».
