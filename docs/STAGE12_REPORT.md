# Ugur Stage 12 — final spacing and card geometry correction

## Исправления

- Верхний голубой блок главного экрана теперь рассчитывает высоту строго по содержимому: убрана возможность появления большого пустого пространства после кнопки «Найти гостиницы».
- Нижний внутренний отступ голубого блока уменьшен.
- «Смотреть все» выровнено по строке заголовка «Популярные места Ашхабада».
- Индикатор прокрутки популярных мест сделан короче и компактнее.
- Белые подписи карточек «Популярные направления» уменьшены по высоте без изменения общей высоты карточек.
- Точки пагинации популярных направлений уменьшены.
- Все карточки избранных гостиниц имеют одинаковую высоту и одинаково зарезервированную строку действия; кнопка «Уточнить у оператора» больше не вызывает overflow.
- Переключатель «Все / В работе / Завершено» на экране запросов сделан компактнее по ширине.
- Добавлен безопасный нижний отступ в запросах, чтобы последняя завершённая карточка полностью прокручивалась выше нижней навигации.
