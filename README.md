# Ugur — Stage 18A

Flutter Web/PWA-приложение для поиска гостиниц Туркменистана.

## Текущий статус

- основа интерфейса: утверждённый Stage 16;
- локальный режим дизайнера: Stage 17;
- чистая структура GitHub и сборок: Stage 18A;
- версия: `1.6.1+20`.

## Главное правило

Утверждённый дизайн нельзя менять без прямого согласия владельца проекта. Ограничения зафиксированы в `DESIGN_LOCK.json`.

## Проверка структуры

```bash
python3 tool/validate_project.py
```

## GitHub Actions

- `.github/workflows/android.yml` — тестовый Android APK;
- `.github/workflows/deploy-web.yml` — Flutter Web/PWA для GitHub Pages.

После загрузки проекта в ветку `main` оба workflow запускаются автоматически. Их также можно запускать вручную во вкладке **Actions**.

Данные пока демонстрационные. Сервер, настоящая авторизация, push-уведомления, административная панель и онлайн-бронирование ещё не подключены.
